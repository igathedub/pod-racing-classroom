Input / output quick guide

Every turn, read two lines with input():

x y checkpoint_x checkpoint_y distance relative_angle
opponent_x opponent_y

Print one command and flush:

target_x target_y thrust

thrust is an integer 0–100, or BOOST once per race. Turn toward the next checkpoint; slow down for tight angles. Keep standard output for commands and send diagnostics to standard error.

In a final with up to five pods, line two describes your nearest opponent, not one fixed rival. Two laps, checkpoint radius 600, rotation limit 18° per turn, friction 0.85. Final pods can collide; qualification uses a non-colliding reference ghost.

This is a classroom variant, not an exact official engine. Read classroom rules
