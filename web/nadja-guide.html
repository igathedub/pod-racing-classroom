Every turn, read one line with input():

x y next_checkpoint_x next_checkpoint_y next_checkpoint_dist winkel

These are six space-separated numbers, not Python variable names sent by the server.

x, y: your pod's current position.
next_checkpoint_x, next_checkpoint_y: the next checkpoint's position.
next_checkpoint_dist: distance to that checkpoint.
winkel: angle to the checkpoint in degrees. Nadja uses the absolute value of the angle because of abs().

Nadja reads these six values with:

x, y, next_checkpoint_x, next_checkpoint_y, next_checkpoint_dist, winkel = [abs(int(i)) for i in input().split()]

Do not read a second opponent line, including in the final.

Nadja prints the target checkpoint and the thrust:

print(next_checkpoint_x, next_checkpoint_y, schub)

schub is an integer from 0 to 100: 0 means no thrust, 50 reduced thrust, and 100 full thrust. Nadja adjusts it using the angle, the distance, and the settings at the top of the example.

For a checkpoint at (7000, 2000) with full thrust, the output is:

7000 2000 100

BOOST can replace the numeric thrust once per race. The supplied Nadja example starts with boost_verfuegbar = False; set it to True to enable the example's one-time boost logic.

Read once and print exactly one command each turn. Keep standard output for commands and send diagnostics to standard error. For immediate output, print(..., flush=True) is also supported.

Practice, qualification and final all run without collisions. Pods pass through each other.
