# Pod Racing Classroom — implementation contract

A real locally hosted classroom site for Python learners. Beginner CodinGame-like two-line observation and one-line action, NOT a claim of an exact official engine. Each student controls one pod; five-pod final is an explicit classroom variant. English UI. Two-hour submission session controlled by teacher. All student execution exclusively in restricted Docker; never a host subprocess fallback. Pure trusted reference bots are allowed for tests/demo. No scraping CodinGame.

## Ownership
Engine agent owns `arena/engine.py`, `arena/bots.py`, `sandbox/Dockerfile`, `sandbox/boot.py`, engine/runner tests in `tests/test_engine.py`, `tests/test_bots.py`, `examples/*.py`.
Backend agent owns `arena/app.py`, `arena/store.py`, `arena/tournament.py`, `tests/test_api.py`, `tests/test_tournament.py`.

Parent owns packaging, dependencies, docs, smoke/browser scripts, integration edits. Do not edit another agent's files. `arena/__init__.py` provided by parent.

## Engine Python API
`make_tracks(seed: int = 2026, count: int = 3) -> list[dict]`: dict keys id, name, checkpoints list [[x,y],...]. Course width16000 height9000, checkpoint_radius600, pod_radius400, rotation18deg/turn except first unrestricted, friction.85, thrust integer0..100, one BOOST650 per pod per race. Deterministic 2-lap races. Checkpoint crossing along segment (not just endpoint). Continuous chronological collisions for final, elastic minimum impulse120. SHIELD optional support (3-turn no thrust, heavy mass during activation) document behavior. Finishing/timeout deterministic. No external assets or engine copying without license attribution.
`run_race(entries: list[dict], track: dict, *, laps: int=2, max_turns: int=700, collisions: bool=True, on_frame=None, runner_factory=None) -> dict`.
Entries keys id, alias, code (str), optional `kind:'reference'` (trusted built-in bot; kind:'student' default). Calls factory(entry) or arena.bots.make_runner(entry). Runner methods `act(observation: str, first: bool=False)->str`, `close()`. First turn observation two newline-terminated lines `x y checkpoint_x checkpoint_y distance relative_angle\nopponent_x opponent_y\n`, nearest other pod in multiplayer; no bootstrap track inputs. Commands `target_x target_y thrust` plus optional label ignored. Proper error classification malformed/timeout/crash/output limit; invalid bots disqualified race continues.
Replay/result dict keys `id` UUID, `track` original dict, `laps`, `max_turns`, `collisions`, `status:'finished'`, `winner_id` nullable, `entries:[{id,alias}]`, `frames:[{turn:int,pods:[{id,alias,x,y,angle,vx,vy,next_checkpoint,passed,finished,disqualified,error,boost_available}]}]`, `results:[{id,alias,place,finished,disqualified,error,turns,passed,distance_to_checkpoint}]` sorted valid finishers then DNF progress then disqualified. `on_frame(frame)` callback every turn; exceptions must close all runners in finally. Store finite numbers only. Qualification reference opponent is allowed; use ghosts collisions=False.
`arena.bots.sandbox_status() -> dict` keys available(bool), detail(str), image(str). Image name `pod-classroom-bot:local`. Must check Docker daemon AND image without pulling/building in HTTP handlers. Container runner startup code supplied via first stdin JSON line to boot.py; subsequent stdin is game's observations. Restricted no networking/host mounts/read-only/drop caps/nonroot/PID-memory-CPU limits/tmpfs and command array no shell. Timeout bounded startup and per turn, cap stdout and stderr, docker rm -f in cleanup. Tests can inject fake runners; Docker integration pytest marker.

## Backend API and persistence
FastAPI; sqlite persisted under data/ (env POD_DATA_DIR override); all IDs UUIDs filenames never aliases. Teacher secret generated on first launch, stored config only, printed server console; `X-Admin-Token` header on admin mutations/teacher reads. NOT exposed via public state. Admin page asks token localStorage/sessionStorage; code/claim tokens not in leaderboard.
Student submission `POST /api/submissions` JSON `{alias,code,claim_token?}` returns `{id,alias,claim_token,version}`. case-insensitive unique alias, claim token required to replace same submission, no takeover; alias1..24 allowed letters/digits/space/_/- (unicode letters okay), code <=32KiB valid Python syntax (AST parse only never exec), forbid updates after deadline/closed/frozen. Teacher starts session -> open, deadline epoch seconds now+duration. On first installation submissions CLOSED until teacher starts; restart retains deadline. Public state deadline expired treated closed regardless worker/timer. JSON errors understandable.
`GET /api/state` -> `{session:{status:'waiting'|'open'|'closed'|'qualifying'|'qualified'|'final'|'finished',deadline:null|float,duration_seconds:7200},submissions:[{id,alias,version,submitted_at}],leaderboard:[{id,alias,rank,completed_tracks,total_turns,progress,disqualified,error?}],job:{status:'idle'|'running'|'finished'|'failed',phase:'qualification'|'final'|null,completed,total,message,error?},sandbox:{available,detail,image},active_replay_id:null|string,replays:[{id,title,kind,created_at,winner_alias?}],finalists:[{id,alias}],champion:null|{id,alias},server_time:epoch seconds}`.
`GET /api/starter` plain Python file download; `GET /api/rules` -> JSON basic protocol; `/` student page, `/teacher` teacher dashboard, `/projector` large race viewer all same SPA index.
`POST /api/admin/session/start` `{duration_seconds:7200}` -> session; `POST /api/admin/session/close` -> session; `POST /api/admin/qualify` ->202 job starts background worker single job lock, closes/freezes submissions, checks Docker available BEFORE change. Each student runs SAME 3 courses (make_tracks), identical starting position against trusted reference ghost collisionsFalse. Save immutable snapshot of submissions for this competition; rank completed_tracks desc, total_turns asc, aggregate progress desc for DNF, never put invalid above valid. Progress tie deterministic id/alias tiebreak documented. Only no-disqualification entries eligible final. Stream active replay snapshots via callback at most 4Hz; do not serialize frames quadratic every turn. Public `GET /api/replays/{id}` returns full current/finished JSON (bounded at max700 turns and <=5 final pods), includes status:'running' for live. Qualification replay include baseline filtered from leaderboard. `POST /api/admin/final` ->202 races best5 eligible snapshot entries in a single simultaneous race collisionsTrue on deterministic showcase track; need at least2 eligible else409; up to5 if fewer but honest UI. Save full replay and champion from winner; never crown crash/DNF as finished winner unless documented tiebreak rules. `GET /api/admin/submissions/{id}` returns code teacher-only. `POST /api/admin/demo` -> inserts6 sample example bots ONLY if empty waiting session; no fake rankings, run actual qualifiers. `POST /api/admin/reset` `{confirm:'RESET'}` explicit UI confirm, reject active job, new session and clears classroom competition records (not admin secret); tests only. Recovery active job interrupted at restart ->failed not stale running. Max60 submissions, request/output replay size bounded, no public code/secret exposure. CORS disabled, only same origin browser; mutations JSON and protected secret for admin. Do not expose runner traceback/secrets to public.

## Frontend
Vanilla HTML/CSS/JS no CDN/network/font dependencies. Race-focused original dark track, warm accent with strong readability, accessible semantic UI/responsive. Main Monitor composition: canvas + standings/list + progress, no centered hero or SaaS feature-card grid. Student `/`: alias, paste editor/file input .py, starter download, instructions, claim-token continuity stored keyed by alias in localStorage (don't use alias as HTML; textContent), submit/update button, syntax errors, closed/deadline countdown, practice code help. Teacher `/teacher`: token entry, session start2h/close, demo insert, qualify, final top5, reset explicit confirm; live job progress; leaderboard; replays dropdown. Projector `/projector`: full race canvas, sorted live standings, race title/status, playback play/pause/speed/scrub, fullscreen, course checkpoints, pod labels/trails, race winner overlays, auto active replay during work. Read public state every2s/replay running <=1Hz no overlapping fetches or resetting playback every poll, error states. Refresh live frames without quadratic paint; interpolation between frames. Explain final nearest opponent input. No inert primary buttons. Public no access teacher secret/code. All API paths per above; frontend handle404/409/503 and Docker offline honestly.
